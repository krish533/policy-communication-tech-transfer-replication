# Manuscript

`main.tex` is the current journal-facing manuscript source for the preferred 34-event design. The `updated34/` directory contains the main sections and appendix modules.

Figures are regenerated by the canonical replication runner and are intentionally not stored as source artifacts. From the repository root:

```bash
python code/reproduce_submission.py
```

Then compile `manuscript/main.tex`. GitHub Actions performs both steps from a clean checkout and uploads the compiled PDF with the replication artifact.

The author field, funding declaration, and author-contribution declaration remain intentionally incomplete until the corresponding human pre-submission decisions are finalized.
